# 18. staff_topのスマートフォン表示

staff_topは、スマートフォンで画面の横幅いっぱいに表示してください。

縦横比を必ず維持してください。

カレンダーのセルを個別に狭くするのではなく、基準サイズで作成したstaff_topのUI全体を等倍率で縮小してください。

staff_topのスケール対象には、参考画像に含まれる以下のUIを含めてください。

- 月切り替え
- スタッフ名
- 店舗別表示
- 曜日見出し
- カレンダー本体

要件：

- 基準となる固定幅をCSSで設定する
- スケール対象要素を作る
- その外側に高さ調整用ラッパーを作る
- transform: scale()を使用してよい
- transform-origin: top leftを使用する
- 横方向と縦方向で同じ倍率を使用する
- 横方向だけを圧縮しない
- セル単位で幅を縮めない
- 文字サイズだけを個別に縮小しない
- 最大倍率は1とする
- PCでは不必要に拡大しない
- スマートフォンでは利用可能な横幅いっぱいに合わせる
- 画面回転時に再計算する
- ウィンドウリサイズ時に再計算する
- 縮小後の高さに合わせて外側ラッパーの高さを調整する
- 縮小後に大きな空白を残さない
- 後続要素と重ならない
- 左右に不要な余白を作らない

倍率の基本計算：

const scale = Math.min(
    1,
    availableWidth / originalWidth
);

originalWidthには、CSS transform適用前の基準幅を使用してください。

# 29. 店舗別ページの初期スクロール

店舗別ページを開いた際、表示中の年月が基準日の年月と一致する場合は、当日の列が最初から画面内に表示されるようにしてください。

当日の列は、横スクロール領域の中央付近へ配置してください。

計算例：

const target =
    todayColumn.offsetLeft
    - scrollContainer.clientWidth / 2
    + todayColumn.offsetWidth / 2;

const maxScroll =
    scrollContainer.scrollWidth
    - scrollContainer.clientWidth;

scrollContainer.scrollLeft = Math.max(
    0,
    Math.min(target, maxScroll)
);

要件：

- ページ表示直後はアニメーションさせない
- DOMレイアウト確定後に実行
- requestAnimationFrameを使用してよい
- 最小スクロール位置を0とする
- 最大スクロール位置を超えない
- 表示月が基準日の年月と異なる場合は月初側を表示する
- ユーザーが手動スクロールした後、勝手に当日へ戻さない
- ウィンドウリサイズ時に必要な再計算を行う
- リサイズのたびにユーザー操作を妨げる位置へ強制移動しない
- 初回表示か、まだユーザーがスクロールしていない場合だけ再調整する

当日列を取得しやすいように、該当する列へ以下のような属性を付けてください。

data-is-today="true"

または：

data-date="2026-07-26"
